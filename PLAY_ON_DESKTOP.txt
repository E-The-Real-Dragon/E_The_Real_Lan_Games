E THE REAL LAN GAMES — HOW TO PLAY (NO CODING NEEDED)
======================================================

PLAYABLE: Checkers + UNO + Cribbage

DESKTOP FOLDER
--------------
  Desktop\E_The_Real_Lan_Games\
    E_The_Real_Lan_Games.exe   <-- double-click this
    _internal\                 <-- leave this folder alone
    README.txt                 <-- short notes

Copy the ENTIRE folder to another household PC to play together.

HOST (your PC)
--------------
1. Double-click E_The_Real_Lan_Games.exe
2. Select Checkers, UNO, or Cribbage on the left
3. Host Game → (Checkers: colors/rules) → Start Hosting
4. Tell the other player the IP shown on screen

GUEST
-----
1. Run the same .exe from a copy of this folder
2. Join Game → type the host IP → Connect

UNO
---
- You only see your own cards
- Drag a card onto DISCARD to play
- Click DRAW to take a card
- Wild → pick a color
- UNO! when you have 1 card

Both PCs must be on the same home Wi-Fi.
